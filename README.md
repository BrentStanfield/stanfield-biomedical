# Stanfield Biomedical LLC Website

A clean, professional one-page website for Stanfield Biomedical LLC preclinical research services.

## Files

- `index.html` - Main webpage
- `style.css` - Styling

## To Preview Locally

Simply open `index.html` in any web browser.

## To Deploy

### Option 1: GitHub Pages (Free)
1. Create a GitHub repository
2. Upload these files
3. Go to Settings → Pages → Select "main" branch
4. Your site will be live at `yourusername.github.io/repo-name`

### Option 2: Netlify (Free, easiest)
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop this folder onto the page
3. Done — you get a free URL instantly
4. Connect a custom domain later if desired

### Option 3: Any Web Host
Upload both files to any web hosting service (Bluehost, GoDaddy, etc.)

## Custom Domain

To use `stanfieldbiomedical.com`:
1. Purchase the domain (Namecheap, Google Domains, etc.)
2. Point DNS to your hosting provider
3. Most hosts have guides for this

## To Edit

- **Content**: Edit `index.html` directly
- **Colors/Fonts**: Edit the CSS variables at the top of `style.css`
- **Contact email**: Update the email address in the contact section of `index.html`

## Notes

- Mobile responsive
- No JavaScript required (pure HTML/CSS)
- Fast loading, SEO-friendly
